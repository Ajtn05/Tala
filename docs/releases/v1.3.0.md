Tala 1.3.0 adds Taglish recognition, a smaller default Whisper model, and optional live transcript review on macOS.

- **Taglish is the default language for new setups.** Tala keeps speech chunks detected as English or Tagalog and skips chunks classified as other languages. Choose **Automatic** in Settings or pass `--language auto` in the CLI to transcribe other supported languages.
- **Everyday & Live is the default transcription model.** It uses Whisper Large v3 Turbo Q5 and takes about 574 MB to download. Choose a different installed model for a recording or import, or set a different default. Tala keeps saved model and language choices.
- **Live transcript review** shows optional suggestions as you record on macOS. A downloadable Whisper model can recheck uncertain words against the audio, or Qwen3.5 can suggest wording from recent transcript lines. Review runs offline after the model download. You can accept or dismiss each suggestion.
- **Fewer captions during pauses.** Local speech detection skips audio without detected speech. Microphone capture also recovers after an input buffer overflow.

## Downloads

- **Tala.dmg** for Apple Silicon Macs running macOS 14.2 or later. Drag Tala to Applications. The app is ad-hoc signed and may require approval in **System Settings → Privacy & Security**.
- **tala-linux-x86_64.tar.gz** for Linux x86_64, built on Ubuntu 24.04. Extract the archive, keep `tala-tools` next to `tala`, and run `./tala --ensure-model`.
- **SHA256SUMS.txt** contains checksums for both packages.
