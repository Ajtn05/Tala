Tala 1.2.0 includes FFmpeg, ffprobe, and yt-dlp in the macOS app and Linux archive. Tala uses these copies automatically, so file and link imports are ready once you set up Whisper.

- Open **New transcription** on macOS to add an audio or video file or paste a supported link.
- The packages include Deno for YouTube links that require JavaScript. Site restrictions and sign-in requirements can still apply.
- Settings shows when file and link imports are ready. You can also run `tala --check-dependencies` from the terminal for details.

## Downloads

- **Tala.dmg** for Apple Silicon Macs running macOS 14.2 or later. Drag Tala to Applications. The app is ad-hoc signed and may require approval in **System Settings → Privacy & Security**.
- **tala-linux-x86_64.tar.gz** for Linux x86_64, built on Ubuntu 24.04. Extract the archive and keep `tala-tools` beside `tala`. Run `./tala --ensure-model` to set up Whisper.
- **SHA256SUMS.txt** contains SHA-256 checksums for both downloads.

Tala can reuse a verified Whisper Large v3 Turbo model from an existing installation. The first model download is approximately 1.6 GB.
