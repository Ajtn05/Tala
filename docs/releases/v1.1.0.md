Tala 1.1.0 restores the macOS app icon and improves local transcription performance.

- The Tala icon now appears in Finder, the Dock, and the app switcher.
- Whisper can use Metal tensor acceleration on M5-class Macs running macOS 26 or later. The Whisper section in Settings shows whether it is active after the model loads.
- Tala starts loading a verified Whisper model while an import prepares or downloads its audio, so transcription can start sooner.
- File and URL imports can skip nearly silent audio windows while preserving source timestamps. Enable **Skip nearly silent import windows** in Recognition settings or use `--skip-quiet-imports` in the CLI. The option is off by default.

## Downloads

- **Tala.dmg** for Apple Silicon Macs running macOS 14.2 or later. Drag Tala to Applications. The app is ad-hoc signed and may require approval in **System Settings → Privacy & Security**.
- **tala-linux-x86_64.tar.gz** for Linux x86_64, built on Ubuntu 24.04. Extract the archive and run `./tala --ensure-model` to set up Whisper.
- **SHA256SUMS.txt** contains checksums for both downloads.

Existing Tala settings, models, and transcripts are stored outside the app and are available after updating. The first model download is approximately 1.6 GB. File imports use FFmpeg and ffprobe. URL imports also use yt-dlp.
