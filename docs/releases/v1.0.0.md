Tala 1.0.0 is the first release from the independent Tala repository. It introduces a new audio capture layer, recording pipeline, and Whisper adapter while keeping the dashboard, media imports, session editor, and exports.

- Record microphone or system audio on macOS, or use the Linux CLI for microphone capture. Stopping a recording drains captured audio before the session closes.
- Transcribe locally with Whisper Large v3 Turbo. Choose an existing verified model or download it from Tala on first use.
- Import files or supported URLs, select an interval, and review or export transcripts as TXT, Markdown, SRT, or VTT. The CLI also exports JSON.
- The macOS app uses its own identity and stores data in Tala’s folders. Sessions from the previous app remain in its workspace.

## Downloads

- **Tala.dmg** for Apple Silicon Macs running macOS 14.2 or later. Drag Tala to Applications. The app is ad-hoc signed and may require approval in **System Settings → Privacy & Security**.
- **tala-linux-x86_64.tar.gz** for Linux x86_64, built on Ubuntu 24.04. Extract the archive and run `./tala --ensure-model` to set up the model.
- **SHA256SUMS.txt** contains checksums for both downloads.

The first model download is approximately 1.6 GB. File imports use FFmpeg and ffprobe. URL imports also use yt-dlp. Physical microphone and system-audio capture still need end-to-end hardware verification. The recording pipeline has been verified with a speech fixture and real Whisper inference.
